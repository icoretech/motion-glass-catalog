# Motion Glass model catalog

Machine-readable model catalog for [Motion Glass](https://motion.glass) — the native macOS
app for AI-directed motion graphics music videos. The app refreshes this catalog at runtime
so new models, prices and deprecations reach existing installs without an app update.

## Canonical URL

```
https://motion.glass/catalog.json
```

Schema `version` 1. Root fields: `schemaVersion`, `generatedAt` (ISO-8601 UTC), `sourceURL`,
`providers[]`, `deprecations[]`.

### Provider

| field | type | meaning |
| --- | --- | --- |
| `provider` | `"anthropic"` \| `"openai"` | provider id |
| `displayName` | string | UI name |
| `apiBaseURL` | URL | default API endpoint |
| `docsURL` | URL | provider docs |
| `models` | Model[] | catalog rows |

### Model

| field | type | meaning |
| --- | --- | --- |
| `id` | string | provider model id (wire id) |
| `displayName` | string | UI name |
| `contextWindow` / `maxOutputTokens` | int | token limits |
| `pricing` | Pricing | USD per million tokens |
| `pricing.inputPerMTok` / `outputPerMTok` / `cacheReadPerMTok` / `cacheWritePerMTok` | number | token rates |
| `pricing.longContext` | object? | `inputTokensAbove`, rates above the threshold |
| `lifecycle` | `active` \| `preview` \| `deprecated` \| `retired` | availability |
| `supportsStructuredJSON` / `supportsVision` / `supportsStreaming` | bool | capabilities |
| `isRecommended` | bool | editorially recommended for the Director role |
| `details` | string? | one-line description for the picker |
| `releasedAt` | ISO date? | release date |
| `replacementID` | string? | successor model id when deprecated |

`deprecations[]` entries: `{provider, modelID, replacedBy?, message, retiresAt?}`.

## Updating

`catalog.json` is generated by `scripts/build_bundled_catalog.py` in the app repo and is also
mirrored inside the app bundle as an offline snapshot. Open a PR here to add models, fix prices
or announce deprecations. Prices are USD API list rates; consumers must treat unknown prices as
"unavailable", never zero.
